Adult Census Income Analysis

CSET485 – AI and Society | Assignment 1

1. Project Overview

This project focuses on analysing the Adult Census Income dataset using Python. It explores demographic, educational and employment-related attributes to understand patterns associated with income levels.

2. Project Objectives

* Explore and understand the dataset.
* Perform data cleaning and preprocessing.
* Conduct Exploratory Data Analysis (EDA).
* Create meaningful data visualisations.
* Identify patterns and relationships between different attributes.
* Present observations and conclusions.

3. Dataset

Adult Census Income Dataset

Source: UCI Machine Learning Repository.

4. Tools and Technologies

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn (if applicable)

5. Project Files

* Adult_Census_Income_Analysis.ipynb – Main project notebook.
* README.md – Project documentation.
* .gitignore – Git configuration.

6. How to Run

1. Open the notebook using Google Colab.
2. Upload or connect the required dataset.
3. Run all notebook cells sequentially.
4. Review the generated analysis and visualisations.

7. Conclusion

This project demonstrates how Python-based data analysis and visualisation techniques can be used to explore census data and identify meaningful patterns in demographic and income-related information.
